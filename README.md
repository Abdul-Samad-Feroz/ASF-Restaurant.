# 🍽️ ASF Restaurant

A responsive restaurant website designed and developed using **HTML, CSS, and Bootstrap**. The project features a clean restaurant-focused interface with dedicated pages for exploring the website, contacting the restaurant, and submitting feedback.

🔗 **Live Demo:** https://asf-resturant.netlify.app

---

## ✨ Features

* 🍽️ Restaurant-focused website design
* 🏠 Dedicated home page
* 📋 Organized food/menu presentation
* 📞 Contact page
* 💬 Feedback page
* 📱 Responsive layout across different screen sizes
* 🧩 Bootstrap-based components and responsive grid system
* 🎨 Custom CSS styling
* 🖼️ Restaurant and food-related visual assets
* 🧭 Easy and straightforward navigation

---

## 🛠️ Technologies Used

* **HTML5** — Website structure and content
* **CSS3** — Custom styling and visual design
* **Bootstrap** — Responsive grid system, layout, and UI components

---

## 🎯 Project Highlights

### 📱 Responsive Design

Bootstrap's responsive grid system was used to create a layout that adapts to different screen sizes and devices.

### 🎨 Custom Styling

Alongside Bootstrap, custom CSS was used to personalize the appearance and create the project's overall visual identity.

### 📄 Multiple Pages

The website is organized into separate pages for different purposes:

* **Home** — Main restaurant website
* **Contact** — Restaurant contact information
* **Feedback** — Visitor feedback page

### 🧩 Bootstrap Integration

The project demonstrates practical use of Bootstrap for building responsive layouts and structuring common website components efficiently.

## 🚀 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/Abdul-Samad-Feroz/ASF-Restaurant.git
```

### 2. Navigate to the project

```bash
cd ASF-Restaurant
```

### 3. Open the website

Open `index.html` in your browser.

You can also use the **Live Server** extension in VS Code for a better development experience.

No additional packages or installation steps are required.
